# Home AI Gatekeeper

### AIの提案と購入実行を分ける — AIDE ARK GATE コンセプトデモ

**Home AI Gatekeeper** は、家庭で使うAIの提案と、実際の購入実行との間に確認の境界を設ける将来構想です。

## アイデア

AIが商品や手続きを提案しても、その提案だけで購入が実行されるべきではありません。購入前に、家族で決めた金額上限や必要な承認を確認し、条件がそろわない場合は処理を保留します。

## 想定する流れ

1. Geminiが利用者の希望に合う商品を候補として提案します。
2. 利用者が購入手続きに進もうとします。
3. AIDE ARK GATEが、家族で設定した金額上限と必要な承認を確認します。
4. 条件が不足している場合は **HOLD（保留）** とし、家族が確認するまで購入へ進みません。

動画では、30万円の商品について必要な条件が満たされず、HOLDになる場面を描いています。

## AIの役割と実行境界

* **Gemini**：希望に沿う商品や購入案を提示します。提案はあくまで候補です。
* **AIDE ARK GATE**：Geminiの提案とは独立して、実行前にルールと承認条件を確認する構想です。
* **家族・利用者**：必要な確認や承認を行います。最終的な購入判断をAIだけに委ねません。

## 期待すること

高額な購入や家族の合意が必要な手続きを、AIの提案だけで進めず、必要な確認を挟めるようにします。将来的には、子どもや高齢者のオンライン購入、定期購入、各種オンライン手続きなどへの応用を想定しています。

## 現在の範囲

このリポジトリは**コンセプトの説明資料**です。家庭用の家族承認機能、商品購入機能、店舗・決済サービスとの連携は実装していません。動画内の画面と購入シナリオは架空のものです。実際の購入・送金や、実在する家族の情報は使用していません。

既存のAIDE ARK GATEデモでは、架空の送金依頼を使った別のシナリオでGemini連携と構造評価を確認しています。そのデモは、このリポジトリで説明する家庭向け機能を実装したものではありません。
